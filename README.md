# Midjourney · 美术方向对照实验

33 页中文网页课件，包含原课件图片、讲解备注、目录、页码跳转和全屏展示。

## 使用

打开 `index.html`，或通过任意静态文件服务器访问本目录。

- ← / →：翻页
- M：目录
- N：讲解备注
- F：全屏
- 点击图片：查看完整原图

所有应用资源均为相对路径，支持 GitHub Pages 项目子路径部署。无构建步骤，无账号登录或数据收集功能。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)。
